# 电商产品详情页设计文案

## 核心定位

全品类电商详情页（健康食品 / 粮油 / 美妆个护 / 家居用品 / 母婴用品服 / 饰鞋包 / 3C 数码 / 家用电器 / 运动户外 / 宠物用品 / 生鲜果蔬 / 酒水饮料 / 礼品文创 / 办公文具 / 汽车用品 / 医药保健 / 家纺床品 / 五金家装 / 玩具潮玩 / 钟表珠宝等）标准化文案生成工具，可直接投喂给AI助手，上传产品基础资料后自动生成完整文案。

---

## 执行铁则

1. **输出格式**：严格9屏结构，每屏包含【文案内容】+【设计要点】+【参考方向】
2. **文案风格**：专业可信 + 共情用户 + 转化导向，规避所有电商违禁词，符合平台合规要求
3. **核心逻辑**：痛点戳中 → 解决方案 → 卖点逐一验证 → 信任背书 → 场景转化 → 信息兜底
4. **关键规则**：第4/5/6屏严格一一对应第2屏的3个核心卖点，适配成分、工艺、原料、技术、体验、安全等所有卖点类型
5. **合规底线**：禁止使用医疗功效词（治疗、预防、抗癌等），禁止夸大宣传，所有数据需有官方检测报告支撑

---

## 输入要求

生成文案前需收集以下信息：
- 产品名称
- 3个核心卖点（与痛点对应）
- 关键参数
- 检测报告 / 认证
- 适用人群
- 规格信息

---

## 9屏标准化输出模板

### 第1屏：痛点引入（黄金3秒抓注意力）

**主标题**：直击用户核心焦虑的反问句（如：你每天用的XX，正在悄悄拖垮生活品质？）

**副标题**：精准定位目标人群（如：精致宝妈 / 上班族 / 注重品质的家庭主妇 / 敏感肌人群）

**3个核心痛点**（严格对应第2屏3个卖点）：
- 【痛点1】：具体场景 + 负面结果（如：普通洗衣液残留多，宝宝皮肤总泛红）
- 【痛点2】：具体场景 + 负面结果（如：成分复杂看不懂，担心有害化学添加）
- 【痛点3】：具体场景 + 负面结果（如：洗后衣物发硬，穿起来不舒服）

**设计要点**：
- 深色 / 低饱和度背景，营造严肃共情氛围
- 大字号加粗主标题，痛点用图标 + 短句展示
- 底部可加小字引导："别急，你要的答案在这里"

**参考方向**：填写对应品类标杆产品首屏

- 【卖点1】：量化数据 + 核心利益（如：0荧光剂0残留，宝宝衣物放心穿）

**设计要点**：
- 产品主图居中放大，卖点用彩色icon环绕排列
- 关键数据用大字号高亮显示
- 干净明亮的白色 / 浅色系背景

**参考方向**：填写对应品类标杆产品卖点屏

**内容模块**：

**设计要点**：
- 信息图表风格，图文结合
- 用对比表 / 误区纠正图展示内容

## 通用规则与禁忌

1. **合规要求**：禁止使用医疗功效词（治疗、预防、抗癌等），禁止夸大宣传，所有数据需有官方检测报告支撑
2. **文案要求**：短句为主，避免长段落，每屏文字不超过200字，重点信息加粗
3. **设计要求**：统一字体和配色，主色调不超过3种，保持全页风格一致
4. **转化要求**：每屏都要有明确的价值引导，从"为什么买"到"现在就买"层层递进
5. **适配要求**：若产品卖点不足3个，可合并对应解析屏；若超过3个，可在第7屏后增加额外卖点解析屏

## 使用说明

1. **收集信息**：获取产品名称、3个核心卖点、关键参数、检测报告/认证、适用人群、规格信息
2. **填入模板**：按9屏结构逐一填写内容
3. **对照参考**：参考同类目标杆产品详情页优化文案
4. **合规审查**：检查所有数据是否有报告支撑，删除违禁词
5. **设计文案**：符合GPT Image 2 文本生图片要求，提供清晰的设计指导
6. **输出结果**：确保9屏内容完整，格式规范，符合转化
