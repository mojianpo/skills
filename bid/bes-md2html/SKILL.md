# md2html

## 表格输出契约

- 对每个 `th` 和 `td` 注入 `.table-cell__content` 容器，视觉上最多展示两行，超出内容隐藏并显示省略效果。
- 在单元格内容容器的 `title` 属性中保留去除 HTML 标签后的完整文本；鼠标悬停时必须能通过浏览器原生 Tooltip 查看完整信息。
- 保留单元格中的链接、强调、代码等原始 HTML，不得为了截断或 Tooltip 将富文本改写为纯文本。
- 表格保持清晰表头、舒适间距、斑马纹与整行悬停反馈；宽表继续使用 `.table-wrap` 横向滚动，不压缩为难以阅读的窄列。
- 验证生成结果同时包含 `.table-cell__content`、`title` 和两行截断样式；表格数量及内容不得丢失。

把现有 Markdown **原样、快速、可靠**地转换为专业、清晰的 HTML。生成结果默认保留一级标题作为文档总标题，并包含基于二级标题的左侧快速导航。默认模板提供克制的现代视觉、可靠的宽表格排版和系统深浅配色；不做多方案设计探索，不生成多套 CSS，不引入 React、Babel、主题切换器或调参面板。

## 执行流程

### 1. 确认输入

1. 找到用户指定的 `.md` 文件；未给路径时，在当前工作目录查找最可能的 Markdown 文件。
2. 只有存在多个候选文件且无法判断时才询问用户。
3. 输出 HTML 必须与源 Markdown 位于同一目录，默认同名并使用 `.html` 扩展名。
4. 用户可以指定输出文件名，但不得指定其他目录；收到异目录要求时说明此技能的同目录约束。

### 2. 转换

优先运行技能自带脚本：

```bash
python scripts/convert.py <input.md> [output.html]
```

第二个参数只用于修改输出文件名，脚本始终把 HTML 写入源 Markdown 所在目录。脚本复用 `assets/base.html`，自动设置页面标题、为每个二级标题生成唯一锚点、创建左侧章节导航，并报告输出信息。

如果脚本提示缺少解析器，运行 `python -m pip install markdown` 后重试。若环境不允许安装依赖，再读取 `references/conversion.md` 的降级方案。

### 3. 按需增强

二级标题左侧导航是默认输出的一部分。仅在用户明确要求时添加三级标题导航、代码高亮、深色模式切换、品牌样式或领域徽章。

不要为了“更美观”主动生成多主题、大段装饰 CSS 或 JavaScript。

### 4. 验证

转换后必须：

1. 确认输出文件存在且非空。
2. 对比源文件与输出中的标题、表格、代码块数量。
3. 检查 HTML 包含 `<!doctype html>`、`<main>` 和闭合的 `</html>`。
4. 检查每个二级标题都有唯一 `id`，且左侧导航包含对应的页内链接；一级标题不进入导航。
5. 检查每个表格都位于 `.table-wrap` 横向滚动容器内，复杂表格不得依靠压缩列宽适配正文宽度。
6. 发现转换缺失时修复后再交付。

### 5. 交付

提供生成文件的可点击路径，并简要报告输出位置、文件大小、已验证结构和任何明确限制。

## 约束

- 保留原文内容、层级、链接、列表、表格和代码块。
- 默认生成一个自包含 HTML 文件，CSS 内联，不依赖网络资源。
- 输出 HTML 必须与源 Markdown 位于同一目录，不创建异目录输出。
- 左侧导航只收录二级标题；一级标题作为文档总标题，不进入导航。
- 桌面端导航保持在正文左侧，窄屏端移到正文上方，打印时隐藏。
- 表格按内容自然分配列宽，单元格保留可读的最小宽度；列较多时由 `.table-wrap` 横向滚动，不把列压成竖条。
- 使用 `assets/base.html` 作为唯一默认模板。
- 不复制或重新发明第二套默认 CSS。
- 不把 Markdown 正文手工改写成 HTML。
- 不因普通转换任务进入设计探索或要求用户挑选风格。
- 不覆盖源 Markdown 文件。

需要修改默认排版或排查转换问题时，读取 `references/conversion.md`；普通转换无需加载该文件。
