# 标书编制工作流

## 资料清单

为每份资料记录：编号、文件名、文件类型、版本或日期、页数、用途、可信度、是否存在冲突。

## 需求拆解

检索并人工复核以下高风险词：

- 强制词：必须、应当、须、不得、禁止、不接受；
- 否决词：无效投标、废标、否决、不予受理；
- 门槛词：不少于、不低于、不超过、至少、有效期内；
- 形式词：签字、盖章、密封、正本、副本、电子签章；
- 时间词：截止时间、交付期、质保期、响应时间。

每条要求拆成最小可验证单元。不要把多个独立要求合并为一个状态。

## 覆盖率

- 强制项覆盖率 = 已满足强制项 / 强制项总数；
- 评分项覆盖率 = 已形成有效响应的评分项 / 评分项总数；
- 证据完整率 = 有 A/B/C 级证据的响应项 / 需要证据的响应项总数。

“待补充”和“部分满足”不计为已满足。终稿的强制项覆盖率必须为 100%，且不存在阻断风险。

## 内容映射

每个评分项必须映射到正文标题、响应表或附件。每个正文承诺必须能回溯到用户资料或用户确认，不允许孤立承诺。

## 版本状态

- 草案：结构或资料尚不完整，可以存在占位符；
- 内审稿：正文基本完整，仍可存在一般风险，不得存在未披露的严重风险；
- 终稿：无占位符、无阻断风险、强制项覆盖率 100%，已完成 DOCX 校验。
