# 资料与证据规则

## 来源优先级

发生冲突时依次采用：

1. 正式澄清、补遗、答疑文件；
2. 招标文件专用条款和评分办法；
3. 招标文件通用条款；
4. 用户明确确认的信息；
5. 投标人证明材料；
6. 行业常识或建议。

同级文件冲突时，记录冲突并优先使用发布日期较新的正式文件。不能可靠判断时列为阻断风险。

## 证据分级

- A：正式证书、合同、验收材料、招标文件原文；
- B：盖章说明、官方系统导出、经确认的内部资料；
- C：宣传资料、未签章清单、用户口头说明；
- D：推测、行业惯例或模型建议。

资格项和废标项不得仅用 C 或 D 级证据证明。D 级内容只能作为建议，不能写成投标人事实。

## 引用定位

内部工作底稿使用：

`[SRC-001｜文件名｜第x页/第x章｜摘录主题]`

正式投标正文是否保留来源标记取决于招标格式。即使正文移除标记，也要在响应矩阵中保留来源定位。

## 缺失与冲突

统一占位符：

`【待补充：内容｜责任人：用户｜影响：阻断/严重/一般】`

禁止使用看似真实的示例名称、证书编号、金额、日期或百分比填补空缺。
